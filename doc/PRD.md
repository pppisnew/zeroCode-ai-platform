# ZeroCode AI Platform - 产品需求文档（PRD）

## 1. 产品目标

构建一个基于 AI 的 Web 应用生成平台，使用户无需编程即可快速创建现代 Web 应用。

平台支持：

* AI 对话生成应用
* 多文件项目生成
* 在线运行与预览
* 可视化拖拽编辑
* 对话式修改
* 项目导出与部署

---

# 2. 核心用户

## 2.1 普通用户

希望无需编程即可创建网站或工具。

## 2.2 独立开发者

快速生成项目原型。

## 2.3 企业产品团队

快速验证 MVP。

---

# 3. 核心功能

## 3.1 AI 应用生成

用户输入自然语言：

“生成一个现代风格的 Todo 应用”

系统自动生成：

* HTML/CSS/JS
* Vue 项目
* React 项目

---

## 3.2 对话式修改

用户继续输入：

“增加深色模式”

AI 自动修改项目。

---

## 3.3 在线运行

支持：

* 实时预览
* 热更新
* iframe 沙箱运行

---

## 3.4 可视化编辑

支持：

* 拖拽组件
* 修改属性
* 实时同步代码

---

## 3.5 项目管理

支持：

* 项目保存
* 历史版本
* 快照恢复

---

## 3.6 项目导出

支持：

* ZIP 下载
* GitHub 导出
* Docker 部署

---

# 4. 非功能需求

## 4.1 性能

* AI 响应时间 < 15 秒
* 页面预览加载 < 2 秒

## 4.2 安全

* iframe 沙箱隔离
* XSS 防护
* 用户权限隔离

## 4.3 可扩展

支持未来：

* 多 Agent
* MCP
* 自动部署
* 插件系统

---

# 5. MVP 范围

## 第一阶段

* AI 生成 HTML
* 实时预览
* 项目保存
* 对话修改

## 第二阶段

* Vue/React 项目
* 多文件生成
* AST 修复

## 第三阶段

* 可视化拖拽
* 多 Agent
* 自动部署
